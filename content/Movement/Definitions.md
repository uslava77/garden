# Freedom
Inverse of freedom:
- Lack of choice
- Lack of ability to choose

Sometimes we describe this as 'being stuck'.

Freedom is:
***Ability choose amongst many paths***

# Freestyle
Freestyle is using freedom to create new: [moves](Dance%20is%20Continuous.md#Move), [combos](Dance%20is%20Continuous.md#Combo) and [sets](Dance%20is%20Continuous.md#Set), *in the present moment.*

See [Choreo to Freestyle Continuum](Choreo%20to%20Freestyle%20Continuum.md)

# Move, Combo, Set
## Move
Some defined movement
## Combo
Multiple connected moves
## Set
Multiple connected combos. 
A complete 'round' start-finish.
## Popular Interpretations
- 6 step is a 'move. Windmill is a 'move'.
- 6 step *to* windmill is a 'combo'
- Salsa step, spin-down, 6-step, windmill, baby freeze is a 'set'

No objective interpretation due to [Dance is Continuous](Dance%20is%20Continuous.md).
