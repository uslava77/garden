# Eternal Return
*"The End IS the Beginning"*

Eternal Return is a system to structure your arsenal such that:

- **Every combo has the same beginning and end position**

This allows us to chain any combo with any other combo in our arsenal.  

Ex. each combo starts and ends in a standing position (useful because we typically enter the round with tops).

Sometimes this position that we re-visit is called a **reset**.

![](eternal-return.png)

# Multi-reset
We can make things a bit more interesting by **adding multiple reset positions**.  

In this system, the beginning and end of a combo can be different.

Ex. some combos begin and end up top, while others end in hook, and others begin with hook.

Thus, we begin to build a combo graph of potential paths we can take.

![](multi-reset.png)

# Black Holes
As you build your multi-reset combo graph, take note of resets with no ways out.
Avoid these black-holes since you might get stuck with no (good) way out during freestyle.

# Hit Rate
If we decide what we want to do right before the round, eternal return ensures a much higher probability of executing what we intend.

Multi-reset increases the cognitive load of this decision since you must also consider if the chosen combos can connect.

# Max Freedom
Eternal return turns out to be [mathematically superior](Combo-inatorics.md) if we only care about the number of different rounds we could potentially construct on the fly.
